폰 화면은 가짜, 대화와 예약은 진짜

테스터 폰에 설치한 여기로 앱이 삼성 전화 앱과 똑같이 보이고, 전화를 걸면 OpenAI 음성 AI가 받습니다. "응" 한 번이면 조중휘 코레일 계정으로 실제 좌석을 잡고, 원터치 결제 화면과 삼성 메시지 화면까지 이어집니다.

한 통화의 순서

재이용 고객이면 어르신이 하는 일은 말 두 번과 탭 한 번입니다. 4·7·10번입니다.

  1. 발신키패드에서 번호를 누르거나 연락처의 "여기로 기차예약"을 누릅니다. 발신 화면과 링백음이 나오는 동안 서버가 세션 키를 발급하고 WebRTC가 연결됩니다.폰 → 서버 → OpenAI
  2. 연결링백이 멈추고 통화 시간이 흐르기 시작합니다. 서버가 사이드밴드로 붙어 자막과 도구 호출을 받습니다.서버
  3. 첫마디여기로 기차 예약 AI예요. 어디로, 언제 가세요?AI
  4. 요청담주 화욜 오후에 서울 좀 가려고어르신
  5. 조회잠시만요, 찾아볼게요. 후 find_trains. 날짜는 코드가 다시 계산하고, 코레일 작업자가 잔여석까지 조회합니다. 노트북이 응답하지 않으면 공공데이터로 조회합니다.서버 → 작업 큐 → 코레일
  6. 제안코드가 만든 문장을 그대로 읽습니다. 날짜·구간·출발·도착·금액, 12초 이하, 예약할까요?로 끝냅니다.AI
  7. 동의응을 확인 모델이 동의로 판정하고 조건 8개를 통과하면 request_booking이 실행됩니다. 응?은 동의가 아니라 열차만 짧게 다시 묻습니다.어르신 → 게이트
  8. 좌석 확보조중휘 계정으로 미결제 예약을 겁니다. 4초가 넘으면 8초마다 자리 잡는 중이에요.작업자 → 코레일
  9. 결제 요청통화 화면 위로 결제 알림이 뜹니다. 화면에 노란 결제 버튼이 떴어요. 눌러 주세요.서버 → 폰
  10. 결제원터치 결제 시트에서 결제하기, 비밀번호 6자리. 돈은 움직이지 않습니다. 90초 동안 누르지 않으면 예약을 풀어 줍니다.어르신 → 서버
  11. 완료결제됐어요. 문자로 보내드렸어요. 결제가 끝난 뒤에만 이 말을 합니다.AI
  12. 문자2초 뒤 문자 알림음과 진동, 헤드업 알림을 누르면 삼성 메시지 화면에 [여기로] 예약 확인.서버 → 폰
  13. 종료조심히 다녀오세요.가 다 재생된 뒤 끊고, 종료음과 함께 통화 종료 화면이 나옵니다.AI → 폰
  14. 정리통화 기록을 확정하고 테스트 예약을 바로 취소합니다. 콘솔에 자막·도구·게이트 판정이 남습니다.서버 → 코레일 · 콘솔

소리 설계

화면을 보지 않고 귀로만 쓰는 서비스라서, 통화의 질감과 기다림의 처리가 곧 UX입니다.

발신과 연결

키마다 DTMF 두 음과 짧은 진동. 한국 링백(440+480Hz)을 최소 한 번 끝까지 들려주고, 그 사이에 연결 지연을 숨깁니다. 연결되면 0.6초 안에 첫마디.

말 차례

semantic_vad를 low로 둬서 천천히 말하거나 중간에 쉬어도 끊지 않습니다. 어르신이 말을 시작하면 AI는 바로 멈춥니다.

스피커폰

스피커를 켠 채로 시작합니다. 에코 제거와 잡음 억제를 켜고, 입력은 먼 거리 기준으로 처리해 AI가 자기 목소리에 끊기지 않게 합니다.

기다림

도구를 부르기 전에 "잠시만요, 찾아볼게요." 한 번. 4초를 넘기면 8초마다 "자리 잡는 중이에요." 침묵이 3초를 넘지 않게 합니다.

숫자와 속도

시각은 "두 시 육 분", 금액은 "만 삼천이십 원". 문장은 코드가 만들고 AI는 그대로 읽습니다. 출력 속도 0.9, 작은 소리는 컴프레서로 끌어올립니다.

침묵과 끝

7초 침묵이면 "천천히 말씀하셔도 돼요." 다시 10초면 정중히 끊습니다. 끝인사가 다 나간 뒤에만 끊고 종료음을 냅니다.

결제와 문자

결제 시트가 뜰 때 알림음, 결제가 끝나면 완료음, 2초 뒤 문자 알림음과 진동. 세 소리가 겹치지 않게 순서를 둡니다.

전화 음질 모드

콘솔에서 켜면 마이크를 300~3400Hz, 8kHz로 깎아 실제 통화 조건에서 인식률을 봅니다. 실험 때 켜고 발표 때 끕니다.

코레일 모드

대화는 모드를 모릅니다. 콘솔 토글 하나로 바꾸고, 노트북 작업자가 4초 안에 응답하지 않으면 서버가 알아서 내려갑니다.

AUTO

실제 조회와 예약

조중휘 계정으로 잔여석 조회와 미결제 예약. 통화가 끝나면 바로 취소합니다.

ASSIST

사람이 대신 예약

공공데이터로 제안하고, 운영자가 콘솔 요청을 보고 코레일+ 앱으로 예약해 예약번호를 넣습니다.

MOCK

리허설과 백업

공공데이터 시간표와 운임에 가짜 예약번호. 발표 중 장애 대비용입니다.

  • 코레일 실시간 조회와 실제 좌석 예약 AUTO일 때

가짜 · 시연 때 밝힘
